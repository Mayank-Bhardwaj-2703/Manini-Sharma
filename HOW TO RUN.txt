=============================================================================
OPTION 1 — DEPLOY TO VERCEL IN 1 MINUTE (LIVE ON THE INTERNET)
=============================================================================

Your project has vercel.json and package.json configured. You can deploy it
instantly to Vercel in either of two ways:

Method A — Via GitHub (Recommended):
1. Create a new GitHub repository (e.g. "dps-vision-2040").
2. Push the contents of the "vision-2040" folder to your GitHub repo:
   cd "/Users/mayankbhardwaj/Desktop/Codlyn Softwares/manini/vision-2040"
   git init
   git add .
   git commit -m "Vision 2040 DPS Mathura Road"
   git branch -M main
   git remote add origin <YOUR_GITHUB_REPO_URL>
   git push -u origin main
3. Go to https://vercel.com/new and click "Import" next to your repo.
4. Framework Preset: Leave as "Other" (Static HTML).
5. Click "Deploy". Your site is live worldwide with SSL in under 15 seconds!

Method B — Via Vercel CLI:
1. In Terminal, navigate to the folder:
   cd "/Users/mayankbhardwaj/Desktop/Codlyn Softwares/manini/vision-2040"
2. Run:
   npx vercel
3. Follow the 3 prompts (hit Enter to accept defaults). Vercel gives you an
   instant production URL!
